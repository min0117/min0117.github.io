Visual Studio

웹사이트 제작과 코딩을 위한 가볍고 빠른 소스코드 에디터이다. HTML, CSS, JavaScript는 물론 다양한 언어와 프레임워크를 지원하며 디자인·프론트엔드 작업에 자주 사용된다. 무료이지만 업계에서도 활용될 만큼 성능이 뛰어나며, 모델링 → 리깅 → 애니메이션 → 이펙트 → 렌더링까지 하나의 프로그램에서 완성할 수 있다는 것이 가장 큰 장점이다.
직관적인 UI 자동완성(IntelliSense) 실시간 오류 체크 확장 프로그램으로 기능 강화 가능 Git 연동
“웹사이트를 만들 때 가장 많이 사용하는 대표적인 코드 편집기입니다.”

교육목표
